# Repository guidance

- Keep the minutes concise: updates, decisions, and next actions.
- Write documentation at an eighth-grade reading level.
- Follow Conventional Commits for every commit, such as `feat: add a minutes example` or `fix: preserve confirmed name spellings`.
- Keep the skill in `skills/committee-meeting-skill` and keep its UI metadata consistent with its instructions.
- Preserve explicit user corrections and distinguish discussion from approval.
- Do not commit actual meeting records, transcripts, email addresses, credentials, or generated document previews.
- Validate YAML frontmatter, names, and relative reference paths after edits. For document output changes, render and inspect representative pages.
