# Committee Meeting Skill

Create short, clear committee minutes from an agenda, transcript, or notes. Each topic explains the update, decision, and next action.

The skill follows the two-page format Richard Lewis chose for St. Peter's October 12, 2026 Board of Properties minutes. It also works for other committees and boards.

## What it does

- Follows the meeting agenda.
- Records who led the meeting, attendance, motions, decisions, and closing time.
- Keeps important costs and dates.
- Names action owners when they are known.
- Leaves out jokes, repeated discussion, and personal remarks.
- Uses confirmed names and preserves later corrections.
- Creates an editable Word document and checks its page layout.

The two-page length is a goal. Longer meetings may need more space.

## Use it

Install the `skills/committee-meeting-skill` folder in your assistant's supported skill location. Then ask:

> Use committee-meeting-skill to create minutes from this agenda and transcript. Keep the updates brief and include decisions and next actions.

The skill needs document-creation tools to produce Word files. It only sends email or creates tasks when you ask it to.
